# Changelog

All notable changes to this project will be documented in this file.

The format is based on [Keep a Changelog](https://keepachangelog.com/en/1.0.0/),
and this project adheres to [Semantic Versioning](https://semver.org/spec/v2.0.0.html).

## [0.1.0] - 2026-10-23

### Added
- Initial release of TokDown.
- Intelligent Tabular Transformation for uniform collections (`_cols` + `_rows`, Markdown Pipe, TSV).
- TOON (Token-Optimized Object Notation) serialization engine.
- Pure-Ruby BPE token count heuristics for OpenAI, Claude, and Gemini.
- Cost savings calculation engine based on current market model rates.
- Unix pipe and STDIN friendly CLI (`bin/tokdown`) with ANSI color telemetry cards.
- Comprehensive RSpec test suite and GitHub Actions CI matrix.
